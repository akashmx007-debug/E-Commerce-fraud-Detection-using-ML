# 🛒 E-Commerce Fraud Detection using Machine Learning

A Machine Learning–based web application that identifies fraudulent online transactions in real-time.  
Built using **Flask + Python + Stacking Classifier + XGBoost**, this system predicts whether a transaction is *Fraudulent* or *Non Fraudulent* based on multiple customer & transaction features.

## 🚀 Features

✅ Real-time fraud prediction  
✅ Flask web UI for user interaction  
✅ Supports multiple ML models — *Stacking Classifier & XGBoost*  
✅ Displays prediction result in a clean tabular format  
✅ Highly scalable and customizable

---

## 🧠 Machine Learning Models Used

| Model | Description |
|--------|-------------|
| **XGB Classifier** | Gradient boosting model known for handling imbalanced fraud datasets |
| **Stacking Classifier** | Ensemble model combining multiple algorithms for higher accuracy |
